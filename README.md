# Что это
Этот python-скрипт модифицирует .h файл GFX-шрифта чтобы он корректно выводил кириллицу штатными средствами библиотеки Adafruit GFX. 

Это позволяет использовать с библиотекой Adafruit GFX в среде Arduino для дисплеев абсолютно любой шрифт, имеющий кириллицу. При этом вывод русского текста осуществляется через обычный print() без всяких дополнительных функций конвертации из UTF-8. Также не требуется никаких замен библиотечных файлов или правок кода библиотеки. Все необходимые изменения осуществляются заранее в самом подключаемом .h файле шрифта. 

# Полный алгоритм добавления любого русского шрифта

### 1. Скачать любой нравящийся вам шрифт, имеющий кириллицу

### 2. Сконвертировать его в формат GFX (вы должны получить файл .h)

Я использую этот конвертер, с ним точно все будет ОК: https://github.com/gi958/AGFXFontEdit

Конвертируется один конкретный размер шрифта, можно задать признаки "жирный", "курсив" и т.д. 

__Обязательно задать "набор символов: кириллица".__

Важно: не используйте этот популярный конвертер, он не добавляет русские символы в .h файл даже если они там были: https://rop.nl/truetype2gfx/

И так делает большинство тех конвертеров, которые я пробовал. Многие еще и специальные символы удаляют.

### 3. Положить полученный файл шрифта исходника в одну папку со скриптом gfx_font_rus_converter.py

### 4. Скачать и установить python если его нет

https://www.python.org/ftp/python/pymanager/python-manager-26.3.msix

### 5. Открыть командную строку (cmd / power shell)

### 6. Перейти в папку где лежит скрипт и шрифт с помощью команды cd

`cd`

### 7. Запустить скрипт
```
python gfx_rus_converter.py FontName.h [FontNameOutput.h]
```

FontNameOutput.h - опциональный параметр.

### 8. Конвертер создаст в той же папке FontNameRus.h (либо FontNameOutput.h).

# Как пользоваться полученным шрифтом

Положить шрифт в папку скетча и в Arduino подключить созданный файл шрифта:
```
#include "FontName.h"
```

Перед использованием шрифта задать его:
```
tft.initR(INITR_BLACKTAB);       // Инициализация
tft.setRotation(TFT_ROTATION);   // Положение дисплея
tft.setFont(&YourFont);          // Установка шрифта
tft.setTextSize(1);              // Масштаб шрифта (допустимые значения 1, 2, 3)
tft.setTextColor(tftColorText);  // Цвет шрифта
```

Вывод русского текста не требует никаких дополнительных функций:
```
tft.fillScreen(tftColorBack);
tft.setCursor(10, 40);
tft.print("Привет, чумба!");
```

# Как это работает

В среде Arduino строки типа "Привет, чумба!" передаются в кодировке UTF-8, которую функция print из библиотеки Adafruit GFX корректно не разбирает.

Код UTF-8 состоит из двух байт на каждую букву, поэтому при попытке напечатать одну букву библиотека попытается найти и напечатать две, да еще и других.

Например, код буквы "я" в UTF-8 это `0xD1 0x8F`. Поэтому print попытается напечатать букву с кодом `0xD1` и затем еще одну с кодом `0x8F`, что соответствуем буквам "Р" и какой то кракозябре.

Скрипт делает две вещи:

1. Он перемещает символы букв кириллицы на другие позиции, соответствующие второму из двух байтов UTF-8. То есть например буква "я" будет перемещена на `0x8F` и заменит собой кракозябру.

2. Чтобы первый байт кода (например `0xD1` для буквы "я") не напечатался, скрипт удаляет из шрифта все символы дальше чем `0xBF` (все первые байты кириллических символов всегда больше чем `0xBF`). И также он меняет параметр шрифта "последний символ" на `0xBF`. Таким образом, если print будет пытаться печатать символы с адресом за пределами этого диапазона - просто ничего не будет напечатано.

Грубо и упрощенно говоря, в файле шрифта на место каждой неправильно отображаемой "кракозябры" устанавливается правильная буква, а заодно все кракозябры удаляются из файла что уменьшает его размер.
