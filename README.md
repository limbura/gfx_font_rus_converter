# Что это
Этот python-скрипт позволяет использовать с библиотекой Adafruit GFX в среде Arduino абсолютно любой шрифт, имеющий кириллицу. При этом вывод русского текста осуществляется через обычный print без всяких дополнительных функций конвертации из UTF-8. Также не требуется никаких замен библиотечных файлов или правок кода библиотеки.

# Полный алгоритм добавления любого русского шрифта

1. Скачать любой нравящийся вам шрифт, имеющий кириллицу.

2. Сконвертировать его в формат GFX (вы должны получить файл .h).
Я использую этот конвертер: https://github.com/gi958/AGFXFontEdit 
Конвертируется один конкретный размер шрифта, можно задать признаки "жирный", "курсив" и т.д. __Обязательно задать "набор символов: кириллица".__
Важно: не используйте этот конвертер, он не добавляет русские символы в .h файл даже если они там были: https://rop.nl/truetype2gfx/

4. Положить полученный файл шрифта исходника в одну папку со скриптом gfx_font_rus_converter.py

5. Скачать и установить python если его нет: 
https://www.python.org/ftp/python/pymanager/python-manager-26.3.msix

6. Открыть командную строку (cmd / power shell).

7. Перейти в папку где лежит скрипт и шрифт с помощью команды 
`cd`

8. Запустить скрипт: 
`python gfx_rus_converter.py FontName.h [FontNameOutput.h]` 
FontOutput - опциональный параметр.

9. Конвертер создаст FontNameRus.h (либо указанное имя).

# Как пользоваться

В скетче Arduino нужно подключить созданный файл шрифта:
`#include <AdafruitGFXFontsRus\Marske20Rus.h>`

Перед использованием шрифта задать его:
```
tft.initR(INITR_BLACKTAB);       // Инициализация
tft.setRotation(TFT_ROTATION);   // Положение дисплея
tft.setFont(&Marske20);          // Установка шрифта
tft.setTextSize(1);              // Масштаб шрифта (допустимые значения 1, 2, 3)
tft.setTextColor(tftColorText);  // Цвет шрифта
```
